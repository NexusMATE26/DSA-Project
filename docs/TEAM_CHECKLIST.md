# First team meeting checklist

1. All three clone the same main branch and successfully compile C++20 M0.
2. Read and approve `docs/DOMAIN_RULES.md` and `docs/DSA_MAPPING.md`.
3. Before code: agree to final interface changes in one shared PR.
4. Member A starts DynamicArray::reserve and pushBack, writes passing tests.
5. Member B reviews HashTable/List API with A and writes collision cases.
6. Member C designs graph edge traversal API and learning-plan examples.
7. In parallel, run a tiny local HTTP/JSON hello-world spike on all laptops.
8. Do not begin the full frontend until services are tested without HTTP.
9. Keep proposal and viva diagrams outside the user website.
